# T-0004 a2: owner corrections to a1

Branch `budgets/t2a-client-gate`, uncommitted. Everything else is as in `T-0004-a1.md`.

## Changes
1. **`src/server/features/projects/services/websiteResearch.ts`: a project refusal now counts as unavailable search, not a failure.**
   - Removed the `searchRefusal` variable and the throw after `generateText`.
   - `searchOutage` is now true when every query was rejected by either an upstream outage or `isProjectDataforseoRefusal`.
   - A refusal therefore makes the tool return the existing "Live search is unavailable. Skip competitor research and return no competitors." error, and the merge forces `competitors: []`.
   - The research completes with its other results and does not hit "Website research was incomplete".
   - A refusal is still not retried. The retry loop only retries `UPSTREAM_UNAVAILABLE`.
   - A refusal mixed with a non-outage failure (for example, auth) with nothing succeeding still falls into the existing incomplete error, the same as before for any non-outage failure.
2. **`src/server/mcp/tool-error-message.ts`: new `PROJECT_BUDGET_EXCEEDED` copy.** It now reads: "This project's DataForSEO allowance is used up. Retrying this or another paid operation won't help until the limit is raised in the project's API spending settings or, for a monthly limit, the next UTC month starts. Saved and cached results remain available."

## Tests
