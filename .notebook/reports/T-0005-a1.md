**Project tab (`ProjectApiSpending.tsx`):**
- A status badge and a status note: paused, not configured (unlimited by default), explicitly unlimited, or limited.
- Five stats:
  - this month recorded, against the monthly limit
  - total recorded, against the total limit
  - in progress
  - estimated, labeled as never confirmed
  - available for new work ("Unlimited", or "None while paused")
- Tracking start date, plus "This month started … 00:00 UTC. Month resets … 00:00 UTC."
- An all-time feature breakdown, and recent usage paginated 25 at a time (time, operation, feature, cost or "~$x estimate", status).

**Limits form (`BudgetLimitsForm.tsx`):**
- Limits are text inputs; an empty input means unset (null) and "0" is a zero limit. The regex `^(\d+(\.\d{1,2})?)?$` enforces at most two decimals.
- The pause switch is part of the same form.
- Owners can also save an unchanged form while the project is unconfigured, which records an explicit "Unlimited".
- Users without `billing: ["manage"]` (from `useCanManageBilling`) see disabled fields and "Only an organization owner can change these limits." I did not use `PermissionHint`: its "owner or admin" copy is wrong here, because admins lack `billing: ["manage"]`.

**Agency table and export (`OrganizationApiSpending.tsx`):**
- Table columns: project, this month, monthly limit, total, total limit, in progress (with "+ $x estimated" when there is any), status.
- A limit column shows "Not set" if the project was never configured and "Unlimited" if an owner chose no limit.
- "Show archived" switch, on by default. Archived rows carry a label and no link, because the project middleware refuses archived projects. Active rows link to their API spending tab.
- CSV export over a date range of UTC days, with the end date inclusive. It is owner-only and reuses `exportRows`.
  - Recorded and estimated amounts get separate columns, written as full-precision text. `buildCsv` rounds numbers to cents, which would turn $0.0006 into $0.00.
  - Opening balances can be found by the Operation column (`opening_balance`).

### Choices where the brief was open
- **CSV export requires `billing: ["manage"]`.** Org-wide billing detail (invoices) is guarded by that permission; the plan/credit summary is only membership-guarded. The export is per-call billing detail with actor ids, so it follows invoices. The overview table needs membership only.
- **Hosted mode refuses with `NOT_FOUND`.** In hosted mode the feature does not exist, which matches how the routes 404.
- **Order inside each handler:** hosted check, then permission, then service.
- **Agency page location:** `/settings/api-spending`, a tab on the existing org-level Settings page.
- **Recent usage paging:** fetch 26 rows to know whether a next page exists, with no count query. The footer shows the exact count once the last page is reached.
- **Error copy (item 4) was already final:** T-0001 had landed the brief's copy in `error-messages.ts`, and both codes in `NON_REPORTABLE_ERROR_CODES`. Only `INSUFFICIENT_CREDITS` triggers the upgrade/credits UI (`QueryError`). Verified; nothing to change.
- **No service or repository additions.** Every read the UI needs already existed.

## Open points / risks
- **`routeTree.gen.ts` was edited by hand.** `tsc` accepts it. The next `vite dev`/build regenerates the file, which may reorder the new lines (cosmetic diff).
- **The read-only form cannot be reached on self-host today.** Delegated auth resolves every self-host user as `owner` (`src/middleware/ensure-user/delegated.ts`), so in practice no self-hoster sees it. It is built and enforced server-side for when self-host gains roles.
- **The export is unbounded.** It returns every row in the range as one server-function payload. That is fine at agency scale. A long range on a heavy deployment could be large; not capped, flagged.
- **Recent-usage times are local; month boundaries are UTC.** At a month edge, a row's local time can fall in a different calendar month than the one it counts against.
- **The notebook context and the code agree,** except that item 4 was already done in T-0001's code.
